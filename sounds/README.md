# Папка sounds/ — свої звуки для гри «Коля Лемак»

Поклади сюди файл з назвою слота, наприклад `kolya_angry.mp3`, і гра відтворить
його замість синтезованого звуку. Якщо файлу немає, грає вбудований синтез (WebAudio).

## Голос Колі
| Слот | Коли звучить |
|---|---|
| kolya_angry | загальна реакція на будь-яку пастку (запасний для всіх kolya_*) |
| kolya_caught_you | Коля спіймав тебе («Ага! Попався!») |
| kolya_suspicious | Коля щось підозрює («Хм?..») |
| kolya_laugh | Коля зловтішається (якщо немає — грає kolya_caught_you) |
| kolya_slip | послизнувся на банані |
| kolya_spit | випив чай із сіллю |
| kolya_yuck | борщ зі шкарпетками |
| kolya_stuck | приклеївся до крісла |
| kolya_scream | будильник о 5 ранку |
| kolya_shiver | крижаний душ |
| kolya_green | позеленів від зеленки |

## Ефекти
prank_success, prank_place, item_pickup, alarm_clock, hide, ui_click,
level_win, game_over, timer_warning

## Формат
- MP3 (або M4A/AAC), моно, 44.1 кГц, 96–128 кбіт/с.
- Тривалість 0.5–2.5 с (голос), без тиші на початку, нормалізована гучність.
- OGG не використовуй — старий Safari його не грає.
- Досить одного файлу `kolya_angry.mp3`: він автоматично звучить для всіх реакцій.
  Кілька варіантів можна задати масивом у SOUND_FILES — гра обиратиме випадково.

## Як підключити
1. **Через сайт (http/https):** просто поклади файли сюди (`sounds/<слот>.mp3` або `.m4a`)
   — гра знайде їх сама (SOUND_AUTOLOAD = true).
2. **Відкриваючи index.html як файл (file://, напр. на iPhone через «Файли»):**
   браузер не дає автоматично читати сусідні файли. Тоді на початку скрипта в index.html
   у `SOUND_FILES` встав base64 data URL:
   `kolya_angry: "data:audio/mpeg;base64,...."`
   (отримати: `base64 -i kolya_angry.mp3` на Mac і додати префікс).
3. Можна вказати й інший шлях або масив: `kolya_angry: ["sounds/a1.mp3","sounds/a2.mp3"]`.

На iPhone звук WebAudio вимикається перемикачем беззвучного режиму — перевір його.
